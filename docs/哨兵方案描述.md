## 1、底盘控制策略

### 1.1 控制目标与输入

采用双舵轮底盘，每个舵轮包含一个驱动电机和一个转向电机，选型分别为GM6020与M3508.

### 1.2 舵轮逆运动学与转向优化

控制器将目标平动和旋转速度合成为每个轮位的速度向量。对于源码中的第 i 个轮，取左轮 s=1、右轮 s=-1，半轮距为 a、半轴距为 b：

为减少转向行程，控制器计算目标角与当前角的最短角度差；若差值超过 90°，则目标转向角反转 180°，同时反转驱动轮速度。目标轮速小于 1 mm/s 时，驱动目标置零并保持当前转向角，避免静止时无意义地转向。

### 1.3 反馈与轮级控制

控制器根据转向编码器、机械标定值和驱动电机转速计算各轮当前角度及线速度，再通过正运动学估算车体 vx、vy、ω。估算角速度经过低通滤波后反馈给云台。该估计依赖轮速和机构模型，轮胎打滑时不等同于实际对地速度。

算法框架使用车体三轴速度 PID 产生合力和力矩，将其分配到两轮并投影至当前轮向，形成驱动电流前馈；驱动轮通过速度 PID 加前馈输出电流，转向轮通过角度 PID 和速度反馈输出电流。电流经限幅后发送。

### 1.4 功率与急停

功率计数据经低通滤波，通过功率 PID，计算 0～1 的比例系数并统一缩放四个电机电流；目标功率不大于零时系数为零，未来计划补充功率建模作为前馈。

底盘接收到约定的急停保留值时复位控制状态并发送复位后的电流。

## 2、云台控制策略

### 2.1 控制模式与目标生成

云台由大 yaw、小 yaw 和 pitch 组成。
姿态融合及 yaw、pitch 控制按 1 kHz 调度，发射机构按 200 Hz 调度。姿态数据无效或急停时复位相应控制输出。

### 2.2 双 yaw 控制

大、小 yaw 分别使用位置 PID，目标和当前角之间按最短角度路径计算误差。小 yaw 根据目标 yaw 跟踪，大 yaw 的目标结合小 yaw 相对角度，使大 yaw 跟随调整。电机速度作为控制阻尼反馈。

底盘通过 CAN1 提供角速度时，控制器将底盘角速度与大、小 yaw 相对转速叠加，构造对地角速度用于阻尼；底盘角速度超过 20 ms 未更新或无效时，退回使用电机相对速度阻尼。

小 yaw 软件工作边界为 ±45°，进入边界前 10° 减速区后逐步削弱继续向外的电流，并根据向外速度施加制动和清除积分。参数与机械零位需按实车校准。

### 2.3 Pitch 与发射机构

位置 PID 使用滤波后的电机速度作为反馈，并传入余弦项用于前馈；靠近限位时逐步削弱向外电流并清除相关积分。前馈的实际作用取决于 PID 参数配置。

发射机构的摩擦轮和拨弹轮采用速度 PID。模式包括停止、摩擦轮和拨弹轮运行、仅摩擦轮运行，以及拨弹轮反转；目标角速度配置为摩擦轮 600 rad/s、拨弹轮 400 rad/s。停止模式下拨弹轮电流清零、摩擦轮以零速为目标减速；急停或未就绪时复位输出。

## 3、双层总线通信架构

### 3.1 架构划分

系统使用两层 CAN 通信：CAN1 是系统层，连接云台板、底盘板和上位机，负责运动命令及状态交换；CAN2 是设备层，每块板分别连接本板电机和相关外设，负责电机反馈及电流控制。两个 CAN 控制器当前均配置为 1 Mbps。各板 CAN2 相互独立。

```text
上位机 ── CAN1 ── 云台板 ── CAN1 ── 底盘板
                    │                    │
               本板 CAN2            本板 CAN2
                    │                    │
             云台与发射电机       舵轮电机、功率计
```

### 3.2 系统层：命令与反馈

CAN 控制模式下，云台板接收上位机底盘命令并转发为；遥控模式下，云台板生成底盘命令。云台板接收增量角度命令或绝对角度命令及的发射命令。

底盘板返回功率和角速度；云台发送角速度、角度、发射状态及姿态。底盘状态和云台状态按 200 Hz 调度。

### 3.3 设备层：执行与采样

底盘 CAN2 接收驱动电机、转向电机和功率计报文；发送驱动、转向电流报文。
