# 双层总线架构与 CAN 通信协议

文档状态：接口评审稿  
更新日期：2026-11-16

## 1. 适用范围

本文规定车载计算机、底盘控制器、云台控制器及 IMU 之间的总线分工、报文标识、数据布局、单位和编码方式，供控制端、嵌入式端及联调人员共同使用。

各端应按本文件的字段顺序、类型和倍率收发数据。相同 CAN ID 不代表与其他版本的载荷兼容，接入前应核对双方协议版本。标为“待确认”的项目尚未形成接口约定。


## 2. 双层架构

系统分为核心总线和各组件内部的域总线。车载计算机、云台控制器、底盘控制器通过核心总线交换命令和状态；控制器通过各自域总线控制电机等设备。

![双层总线硬件拓扑](assets/双层总线旧版拓扑.png)

| 层级 | 接口 | 用途 |
| --- | --- | --- |
| 核心总线／跨层通信 | CAN1 | 车载计算机与控制器、底盘与云台之间的命令和状态 |
| 域总线／同层通信 | CAN2 | 各控制器所属电机、驱动器等本地设备通信 |

同一层级使用 CAN2，跨层级通信使用 CAN1。底盘域与云台域的 CAN2 为独立物理网络。

## 3. 数据编码与坐标约定

多字节字段采用小端序，低字节在前；字节偏移从 0 开始。`int16_t` 采用 16 位有符号补码，`uint16_t` 为 16 位无符号整数，`uint8_t` 为 8 位无符号整数。报文按经典 CAN 单帧最多 8 字节设计；下文长度均以字节为单位。

### 3.1 统一类型与倍率

编码值 = 物理值 × 倍率；解码值 = 编码值 ÷ 倍率。

| 物理量 | 线上类型 | 物理单位 | 倍率 | 分辨率 | 类型可表示范围 |
| --- | --- | --- | ---: | --- | --- |
| 平移速度 | `int16_t` | mm/s | 1 | 1 mm/s | −32768～32767 mm/s |
| 角速度 | `int16_t` | rad/s | 1000 | 0.001 rad/s | −32.768～32.767 rad/s | 
| 角度 | `int16_t` | rad | 10000 | 0.0001 rad | −3.2768～3.2767 rad |
| 实际功率 | `int16_t` | W | 100 | 0.01 W | −327.68～327.67 W |
| 允许功率百分数 | `int16_t` | % | 100 | 0.01 个百分点 |0～100%，编码 0～10000 |
| C 板四元数分量 | `int16_t` | 无量纲 | 30000 | 1/30000 |编码 −30000～30000 |
| 开关、枚举、标志位 | `uint8_t` | 无 | 无 | 按枚举定义 | 0～255 | 

### 3.2 精度与溢出

若采用四舍五入到最近整数，定点量化的最大绝对误差为半个刻度：平移速度 0.5 mm/s、角速度 0.0005 rad/s（约 0.02865°/s）、角度 0.00005 rad（约 0.002865°）、功率 0.005 W、功率百分数 0.005 个百分点、四元数每分量约 0.00001667。

角度统一采用 ×10000，角速度指令与反馈统一采用 ×1000。角速度 10 rad/s 编码为 10000，功率 300 W 编码为 30000，均能由 `int16_t` 表示。

以上误差仅为编码量化误差，不包含传感器误差、控制误差、延迟或坐标转换误差。若直接截断，误差可接近一个刻度，且正负误差可能不对称。具体舍入方式及越界时拒绝、限幅等处理规则待确认；禁止将溢出回绕视为有效物理量。角度 ×10000 不适合直接传输多圈累计角度。

### 3.3 坐标约定

向前为 x，向左为 y，向上为 z；底盘绕 z 逆时针为正。各控制器的安装方向与该坐标系的映射关系需在联调前确认。

云台采用右手约定：yaw 向左为正，pitch 向下为正。常规单圈角度区间为 `(−π, π]`；pitch 实际可用范围由机械限位决定。绝对角度的参考坐标系、零位以及 IMU 姿态与机械角的映射待确认。

## 4. 核心应用报文总览

“接收／发送”均以对应底盘或云台控制器为参照。

| CAN ID | 方向／接收对象 | 含义 | 有效长度 |
| --- | --- | --- | ---: |
| `0x111` | 控制端 → 底盘 | 底盘速度指令 | 8 |
| `0x113` | 控制端 → 底盘 | 阿克曼底盘指令 | 4 |
| `0x115` | 控制端 → 底盘 | 跟随模式指令 | 8 |
| `0x112` | 底盘 → 核心总线 | 实际功率、实际 z 角速度反馈 | 4 |
| `0x120` | 雷达／上位机 → 云台 | 雷达底盘运动指令 | 8 |
| `0x121` | 控制端 → 云台 | 角速度控制，不发射 | 4 |
| `0x123` | 控制端 → 云台 | 绝对角度控制，不发射 | 4 |
| `0x125` | 控制端 → 云台 | 角速度控制，发射 | 4 |
| `0x127` | 控制端 → 云台 | 绝对角度控制，发射 | 4 |
| `0x129` | 控制端 → 云台 | 发射机构控制 | 2 |
| `0x122` | 云台 → 核心总线 | 云台角速度反馈 | 4 |
| `0x124` | 云台 → 核心总线 | 云台角度反馈 | 4 |
| `0x126` | 云台 → 核心总线 | 发射机构反馈 | 待定义 |
| `0x031` | 控制器 → 达妙 IMU | 寄存器请求 | 4 |
| `0x039` | 达妙 IMU → 控制器 | 欧拉角反馈，见第 7 节 | 8 |
| `0x233` | C 板 → 接收端 | 四元数 | 8 |

底盘 ID 规划区间为 `0x111～0x119`，云台 ID 规划区间为 `0x120～0x129`。未列出的 ID 暂无载荷定义。

## 5. 底盘接口

### 5.1 底盘速度指令 `0x111`

| 字节 | 类型 | 字段 | 解码方式 |
| --- | --- | --- | --- |
| 0～1 | `int16_t` | vx | 原值，mm/s |
| 2～3 | `int16_t` | vy | 原值，mm/s |
| 4～5 | `int16_t` | wz | 原值 / 1000，rad/s |
| 6～7 | `int16_t` | 允许功率百分数 | 原值 / 100，% |

`wz` 表示绕 z 轴的角速度，单位为 rad/s。

### 5.2 阿克曼底盘指令 `0x113`

| 字节 | 类型 | 字段 | 解码方式 |
| --- | --- | --- | --- |
| 0～1 | `int16_t` | 驱动速度 | 原值，mm/s，向前为正 |
| 2～3 | `int16_t` | 前轮转角 | 原值 / 10000，rad，向左为正 |

前轮实际转角限位待确认。

### 5.3 跟随模式指令 `0x115`

| 字节 | 类型 | 字段 | 解码方式 |
| --- | --- | --- | --- |
| 0～1 | `int16_t` | vx | 原值，mm/s |
| 2～3 | `int16_t` | vy | 原值，mm/s |
| 4～5 | `int16_t` | wz | 原值 / 1000，rad/s |
| 6～7 | `int16_t` | 云台角度 | 原值 / 10000，rad |

云台角度的参考系，以及跟随模式中 wz 的控制含义，待确认。

### 5.4 底盘状态反馈 `0x112`

| 字节 | 类型 | 字段 | 解码方式 |
| --- | --- | --- | --- |
| 0～1 | `int16_t` | 实际功率 | 原值 / 100，W |
| 2～3 | `int16_t` | 实际 wz | 原值 / 1000，rad/s |

功率测量位置、是否允许负值及滤波口径待确认。

## 6. 云台与发射机构接口

### 6.1 雷达指令 `0x120`

载荷为 8 字节，字段布局与 `0x111` 完全相同。该指令经云台转发至底盘，底盘接收 ID 为 `0x111`。转发周期、控制源选择以及与遥控器指令的优先级待确认。

### 6.2 角速度指令 `0x121`、`0x125`

| 字节 | 类型 | 字段 | 解码方式 |
| --- | --- | --- | --- |
| 0～1 | `int16_t` | yaw 目标角速度 | 原值 / 1000，rad/s |
| 2～3 | `int16_t` | pitch 目标角速度 | 原值 / 1000，rad/s |

`0x121` 为不发射模式，`0x125` 为发射模式。字段表示目标角速度，不表示单帧角度增量。不能直接将每帧数值累加为角度；若控制器需要角度目标，应按实际时间间隔积分角速度。

发射模式与 `0x129` 的优先级、零角速度是否仍允许发射均待确认。

### 6.3 绝对角度指令 `0x123`、`0x127`

| 字节 | 类型 | 字段 | 解码方式 |
| --- | --- | --- | --- |
| 0～1 | `int16_t` | yaw 目标绝对角度 | 原值 / 10000，rad |
| 2～3 | `int16_t` | pitch 目标绝对角度 | 原值 / 10000，rad |

`0x123` 为不发射模式，`0x127` 为发射模式。零值是合法角度，不代表目标丢失或停止。pitch 机械限位待确认。

`0xFFFF` 按普通有符号整数 −1 解码，表示 −0.0001 rad，不作为目标有效性标志。目标丢失的通知方式待确认。

### 6.4 发射机构控制 `0x129`

| 字节 | 类型 | 字段 | 编码 |
| --- | --- | --- | --- |
| 0 | `uint8_t` | 摩擦轮开关 | `0xFF` 开，`0x00` 关 |
| 1 | `uint8_t` | 拨弹盘状态 | `0x00` 正转，`0xAA` 停转，`0xFF` 反转 |

全零报文表示“摩擦轮关、拨弹盘正转”，不能把全零视为发射机构全部停止。

摩擦轮关闭时是否强制禁止拨弹、与发射模式 ID 如何联动、状态持续时间和非法枚举处理待确认。

### 6.5 云台反馈

| ID | 字节 0～1 | 字节 2～3 | 类型与解码 |
| --- | --- | --- | --- |
| `0x122` | yaw 实际角速度 | pitch 实际角速度 | 两个 `int16_t`，分别 /1000，rad/s |
| `0x124` | yaw 实际角度 | pitch 实际角度 | 两个 `int16_t`，分别 /10000，rad |

反馈角度的坐标系应与绝对角度指令一致，具体基准待确认。`0x126` 为发射机构反馈保留接口，字段及 DLC 未定义。

## 7. 达妙 IMU 原生接口

达妙 IMU 使用原生寄存器协议。其欧拉角载荷采用无符号区间映射，与应用层的有符号定点角度编码不同。

### 7.1 ID 与设备配置

| 项目 | CAN ID |
| --- | --- |
| 控制器请求 | `0x031` |
| IMU 反馈 | `0x039` |

设备 ID 与控制器收发配置必须与上表一致。设备 ID 配置方法、物理总线位置及请求周期待确认。

### 7.2 请求报文 `0x031`

DLC 为 4，标准数据帧，由控制器发往 IMU。

| 字节 | 类型 | 含义 |
| --- | --- | --- |
| 0 | `uint8_t` | 固定 `0xCC` |
| 1 | `uint8_t` | RID，寄存器选择 |
| 2 | `uint8_t` | `CMD_READ = 0x00`，`CMD_WRITE = 0x01` |
| 3 | `uint8_t` | 固定 `0xDD` |

欧拉角读取请求为 `CC 03 00 DD`。

| RID | 数据类别 | 当前定义范围 |
| --- | --- | --- |
| `0x01` | 加速度 | 响应格式待补充 |
| `0x02` | 角速度 | 响应格式待补充 |
| `0x03` | 欧拉角 | 本节给出完整读取载荷 |
| `0x04` | 四元数 | 响应格式待补充 |

写命令所需载荷与具体写入流程尚未定义。

### 7.3 欧拉角反馈 `0x039`

DLC 为 8。线上角度为三个无符号 16 位整数，解码结果为角度值。

| 字节 | 线上类型 | 含义 | 映射范围 |
| --- | --- | --- | --- |
| 0 | `uint8_t` | REG，欧拉角 RID 预期 `0x03` | 字段校验规则待确认 |
| 1 | `uint8_t` | const_0，预期 `0x00` | 字段校验规则待确认 |
| 2～3 | `uint16_t`，小端 | pitch 原始编码 | −90～90° |
| 4～5 | `uint16_t`，小端 | yaw 原始编码 | −180～180° |
| 6～7 | `uint16_t`，小端 | roll 原始编码 | −180～180° |

原始值 `u` 的解码公式：

```text
u = low_byte | (high_byte << 8)
angle_deg = u * (max_deg - min_deg) / 65535 + min_deg
angle_rad = angle_deg * π / 180
```

pitch 分辨率约 0.00274662°（0.00004794 rad），yaw/roll 分辨率约 0.00549325°（0.00009588 rad）。若传感器采用最近值量化，最大编码误差约半个刻度；传感器内部量化方式待确认。

该编码采用区间映射，不是 `int16_t` 补码，也不是“角度 × 固定倍率”。`u=0` 对应负量程端点，`u=65535` 对应正端点；中点 32767/32768 分别位于零点两侧，因此不一定能精确表示零。

将此反馈转换到应用角度 ×10000 时，会再次量化。采用最近值舍入时，转换本身额外误差最多 0.00005 rad；不得将应用层精度误认为传感器实际精度。

IMU 安装方向、坐标映射和输出角与云台机械角的关系待确认。

### 7.4 C 板四元数 `0x233`

| 字节 | 类型 | 字段 |
| --- | --- | --- |
| 0～1 | `int16_t` | q0 ×30000 |
| 2～3 | `int16_t` | q1 ×30000 |
| 4～5 | `int16_t` | q2 ×30000 |
| 6～7 | `int16_t` | q3 ×30000 |

解码后各分量除以 30000。q0 是否为标量、旋转方向、坐标系及旋转顺序待确认。四元数量化后模长可能偏离 1，接收端使用前可检查并归一化，零四元数不能作为有效姿态。

## 8. 裁判系统接口

本节定义裁判信息的 CAN 转发格式。裁判数据来源、有效性、更新周期及适用规则版本待确认。裁判系统 ID 规划区间为 `0x151～0x159`，底盘通过 CAN1 上发。

### 8.1 剩余热量 `0x151`

有效长度 2 字节：字节 0～1 为小端 `int16_t`，表示允许热量减当前热量。字段无附加倍率；热量单位及负值处理待确认。

### 8.2 场地反馈 `0x153`

有效长度 8 字节。

| 字节 | 类型 | 含义 |
| --- | --- | --- |
| 0 | `uint8_t` | bit0～3 比赛阶段；bit4～7 血量变化类型 |
| 1～2 | `uint16_t` | 当前阶段剩余时间，秒，小端 |
| 3 | `uint8_t` | 最后一次判罚等级 |
| 4 | `uint8_t` | 最后一次判罚涉及的违规机器人 ID |
| 5 | `uint8_t` | 占领、RFID 和 shooter 电源标志，见下表 |
| 6 | `uint8_t` | 回血增益百分数，10 表示每秒恢复血量上限的 10% |
| 7 | `uint8_t` | （17 mm 射击热量 / 射击热量上限）×255 |

比赛阶段：0 未开始、1 准备、2 十五秒自检、3 五秒倒计时、4 比赛中、5 结算。血量变化类型：0 装甲被弹丸攻击、1 装甲或超级电容管理模块离线、5 装甲撞击；其他值未定义。

| 字节 5 的位 | 含义 |
| --- | --- |
| bit0 | 己方补给区占领状态，1 已占领 |
| bit1～2 | 中心增益点占领：0 无、1 己方、2 对方、3 双方 |
| bit3 | RMUL 补给区 RFID 是否检测到 |
| bit4 | 中心增益点 RFID 是否检测到 |
| bit5 | shooter 口电源：0 无输出，1 为 24 V 输出 |
| bit6～7 | 保留 |

回血增益按百分数 ×1 编码，与允许功率百分数 ×100 的倍率不同。

### 8.3 机器人反馈 `0x155`

有效长度 8 字节，四个小端 `uint16_t`：

| 字节 | 含义 |
| --- | --- |
| 0～1 | 本机器人当前血量 |
| 2～3 | 本机器人血量上限 |
| 4～5 | 己方 1 号英雄血量 |
| 6～7 | 己方 3 号步兵血量 |

未上场或被罚下的队友机器人血量为 0。

### 8.4 其他信息 `0x157`

有效长度 1 字节：`uint8_t` 本机器人 ID；示例： 7 表示红 7，107 表示蓝 7。

## 9. 导航与转发接口

### 9.1 地图标定通知 `0x161`

表示地图标定完成。载荷、DLC、确认与重发机制待定义。

### 9.2 转发映射

转发 ID 规划范围为 `0x200` 以上。具体源总线、目标总线、源 ID、目标 ID、方向及防回环机制待确认。该范围不构成无条件转发规则，已定义的 `0x233` 按四元数接口处理。

## 10. 接口兼容要求

双方应核对每个 ID 对应的字段类型、倍率、字节顺序和有效长度。两个 `int16_t` 字段共 4 字节，`0x129` 的两个 `uint8_t` 字段共 2 字节。

表中有效长度由已定义字段确定。是否要求 DLC 严格等于有效长度、是否支持固定 8 字节填充，以及填充内容与长度不匹配时的处理方式，均待确认。

以下仅核对字段编码，不定义控制动作时序。所有多字节字段均为小端。

| --- | --- | --- |
| `0x111` | vx=1000 mm/s，vy=−500 mm/s，wz=1 rad/s，允许功率100% | `E8 03 0C FE E8 03 10 27` |
| `0x112` | 功率300 W，wz=−10 rad/s | `30 75 F0 D8` |

## 12. 待确认清单

6. 发射反馈 `0x126`、导航 `0x161` 的完整格式，扩展角度反馈 `0x130` 是否启用。
7. IMU 的设备 ID 设置步骤、物理总线位置、请求周期、其他寄存器及写协议。
8. 裁判系统规则版本、热量单位、热量比越界或分母为零的处理。
